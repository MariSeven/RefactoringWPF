# RefactoringWPF

Исправила всё по заданию. Вот что сделала:

1.  **Таблица пустая.** Поля переделала в свойства + `INotifyPropertyChanged`. Теперь DataGrid видит данные.
2.  **Таблица не обновлялась.** Заменила `List<Order>` на `ObservableCollection<Order>`. Новые заказы появляются сами.
3.  **Программа падала от букв.** Заменила `int.Parse` на `int.TryParse`. Если ввели не число — программа не сломается.
4.  **Кнопка «Удалить» ломала всё.** Добавила проверку `if (selectedOrder == null) return;`. Без выделения кнопка ничего не делает.
5.  **Один класс делал всё.** Разделила `OrderService` на несколько классов. Каждый отвечает за своё.
6.  **Окно само создавало сервисы.** Убрала `new OrderService()` из `MainWindow`. Сервисы теперь передаются через конструктор.
7.  **Логика была в файле окна.** Перенесла код из `MainWindow.xaml.cs` в папку `Services/`. Окно теперь только показывает интерфейс.
8.  **Скидки через if-else.** Сделала паттерн Стратегия: `IDiscountStrategy`, `PercentDiscount`, `FixedDiscount`. Чтобы добавить новую скидку, не нужно трогать старый код.
9.  **Формула суммы повторялась.** Оставила расчёт в `Order.CalculateTotal()`. Остальные методы просто вызывают его.
10. **Два метода делали одно и то же.** Удалила `FormatMoneyShort`, оставила один `FormatMoney`.
11. **Статусы были строками.** Сделала `enum OrderStatus { New, Paid, Shipped, Cancelled }`. Теперь нельзя написать статус с ошибкой.
12. **Числа без названий.** Вместо `10000` теперь `const decimal MinAmountForDiscount = 10000m;`. Сразу видно, что это порог для скидки.
13. **Кнопки назывались одинаково.** Переименовала `Button_Click_1` в `AddOrderButton_Click`, `Button_Click_2` в `DeleteOrderButton_Click`.
14. **Был ненужный код.** Удалила `Helper.CalculateSomething` — его никто не использовал.
15. **Непонятный параметр в методе.** Разделила `UpdateStatus(id, status, bool writeLog)` на два метода: `UpdateStatus` и `UpdateStatusWithLog`.
16. **Email проверялся плохо.** Заменила проверку на `@` и `.` на `new MailAddress(email)`. Кривые адреса больше не проходят.
17. **Подсказки в полях путали.** Вместо `Text="Customer"` сделала стиль placeholder. Подсказка серая и исчезает при вводе.
18. **Колонки таблицы сами генерировались.** Выключила `AutoGenerateColumns="True"`, прописала колонки вручную: `<DataGridTextColumn Header="Заказчик" Binding="{Binding CustomerName}" />`.
